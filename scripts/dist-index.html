FRPanel 一键部署v1.0.1

复制下方命令，分别在「家中面板主机」与「公网节点」以 root 执行即可。

① 部署面板（家中 Debian 13 主机）

安装管理面板本体。将交互询问数据库信息与监听端口（回车随机）。

升级：在命令末尾追加 -s -- --upgrade；安装后 SSH 输入 frppanel 可回看安装信息。

② 部署节点 Agent（公网云服务器 Ubuntu 22.04）

安装 frps + Agent，输出注册回执，粘贴回面板「添加节点」即可。

卸载：命令末尾追加 -s -- uninstall（仅移除本项目组件）。国内网络可加 -s -- --mirror <前缀>。
